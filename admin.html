PicGo / ShareX 对接

接口：/api/upload（POST），图片用 multipart 字段 file 上传，鉴权头 X-Admin-Token = 发布密码，返回 JSON 里的 url 即外链。

PicGo「自定义 Web 图床」：
  API 地址   https://你的域名/api/upload
  请求方式   POST
  表单字段   file  （文件字段）
  请求头     X-Admin-Token: 你的发布密码
  URL 后缀   data.url

ShareX「自定义上传器」：
  Method     POST
  URL        https://你的域名/api/upload
  Headers    X-Admin-Token = 你的发布密码
  Body       Form(Multipart)，文件字段名 file

download备份

导出文章与时间线，或导入备份恢复。恢复会替换云端全部文章与时间线，请先保存当前备份。

· 本页面不含任何密码（运行时输入），可放心部署到 Pages（地址：你的站/admin.html），也可以只在本地使用。

· 发布 = 新增或覆盖；删除文章需后端支持 DELETE 接口（见配套说明），未更新前请到 KV 面板手动编辑 posts 键。

· 修改文章：在“云端文章”里点 edit 载入 → 改完再点“发布文章”即可。

· 时间线：每条后面点 edit 载入修改（再点一次可取消），点 delete 删除；编辑时“追加”按钮会变为“保存修改”。

· 代码块：点“代码块”插入后，任何语言的代码直接粘贴进去即可，尖括号、引号等符号按纯文本原样显示，不需要手动转义。

· 图床：图片存 Cloudflare R2，经 content_copy 复制外链后用“图片”标签插进正文；截图后直接 Ctrl+V 可自动上传并插入。PicGo / ShareX 见图床卡片里的对接说明（需在后端绑定 R2 桶 IMG_R2）。

· 封面：表单里可上传 / 图库点选 / 填 URL 设置封面（显示在首页卡片与置顶大卡片）；“恢复默认”即删除封面，按分类用 loremflickr 自动生成。
